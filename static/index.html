PyThaiTTS (Kokoro-82M) FastThaiG2P / Kokoro ONNX ระบบ NLP เตรียมข้อความในตัว แปลงตัวเลข ไม้ยมก และ IPA อัตโนมัติ จัดการเลขอารบิกและคำทับศัพท์อังกฤษได้ดีเยี่ยม CPU ออฟไลน์ เบามาก Apache-2.0
PyThaiTTS (MakHam) MakHam Paradee ONNX ขนาดเล็กจิ๋วเพียง ~8MB รวดเร็วระดับเสี้ยววินาที เหมาะกับ Edge Devices อ่านคำทั่วไปได้ดี เสียงโทนเรียบ ต่ำมาก (~8MB) Apache-2.0
OmniVoice Thai 0.6B Language-Diffusion เป็นธรรมชาติระดับสูงสุด ออกเสียง ร ชัดเจนสมจริงมาก รองรับ Zero-shot เสียงพูดธรรมชาติที่สุด แต่อาจมีพลาดเรื่องตัวเลขบ้าง สูงมาก (Weights ~4.4GB, GPU แนะนำ) Apache-2.0 (ดู Dataset NC)
F5-TTS-THAI / OpenJaiTTS Flow Matching (Diffusion) โคลนเสียง (Voice Cloning) จากตัวอย่าง 5-10 วินาทีได้ทันที v2 (IPA) ลดการข้ามคำ ประโยคยาวควรแบ่งย่อย ปานกลาง-สูง (VRAM 2-4GB) MIT / CC-BY-NC-4.0
Edge Neural (Cloud) Microsoft Neural TTS เสียงระดับ Commercial ชั้นนำ ใช้เป็นตัววัดอ้างอิง (Ground Truth) แม่นยำสูงมาก จังหวะการพูดสมบูรณ์แบบ ต้องต่ออินเทอร์เน็ต Cloud Service

สรุปข้อมูลทางเทคนิค วิธีติดตั้งโมเดลขนาดใหญ่ และการเลือกใช้งานตามความเหมาะสมของฮาร์ดแวร์

ข้อมูลฮาร์ดแวร์ในเครื่องของคุณ: NVIDIA GeForce RTX 3050 Laptop GPU (4GB VRAM)

เครื่องของคุณมี VRAM ประมาณ 4GB (มีแอปพลิเคชันอื่นใช้งานอยู่บางส่วน) โมเดลที่เหมาะสมสำหรับการใช้งานแบบ Production ที่รวดเร็วและไม่กระตุกคือ VachanaTTS (ONNX) และ PyThaiTTS (Kokoro / MakHam) ซึ่งกินทรัพยากรน้อยและประมวลผลบน CPU/GPU ได้ทันที

OmniVoice Thai (hotdogs/omnivoice-thai)

Diffusion 0.6B

โมเดล Fine-tune ภาษาไทยจาก OmniVoice ใหญ่ ~0.6 พันล้านพารามิเตอร์ ผลการทดสอบจากชุมชนยอมรับว่า ให้อารมณ์เสียงและความเป็นธรรมชาติของภาษาไทยดีที่สุด โดยเฉพาะการออกเสียงพยัญชนะ "ร" ที่ชัดเจนและเป็นธรรมชาติ

# ตัวอย่างการเรียกใช้ OmniVoice Thai ใน Python:
pip install omnivoice soundfile
from omnivoice import OmniVoice
import soundfile as sf
model = OmniVoice.from_pretrained("hotdogs/omnivoice-thai")
wav = model.generate_speech("ข้อความภาษาไทย", language="th")
sf.write("output.wav", wav, 24000)
ข้อควรระวัง: น้ำหนักโมเดลมีขนาด ~4.4GB ต้องการแรมและ GPU สูง

F5-TTS-THAI & OpenJaiTTS

Flow Matching / Cloning

พัฒนาด้วยเทคนิค Flow Matching รองรับการโคลนเสียง (Voice Cloning) แบบ Zero-Shot จากตัวอย่างเสียงเพียงไม่กี่วินาที รุ่น v2 (IPA) ช่วยลดปัญหาการข้ามคำและคำซ้ำได้ดียิ่งขึ้น

# ตัวอย่างการเรียกใช้ F5-TTS ภาษาไทย:
pip install f5-tts-th
from f5_tts_th.tts import TTS
tts = TTS(model="v2")
wav = tts.infer(ref_audio="ref.wav", ref_text="...", gen_text="...")
เคล็ดลับ: ข้อความที่ยาวมากควรแบ่งย่อยเป็นท่อนๆ แล้วนำมารวมกัน

ระดับงานวิจัยล่าสุด: JaiTTS-v1.0 (สถาปัตยกรรม VoxCPM)
